# 十大打法操作手册

每个打法：何时用 → 输入要求 → 操作步骤 → 输出模板 → 常见坑。

---

## 1. 指标拆解（加法/乘法/杜邦）

**何时用**：综合指标变了（GMV、利润、营收），要回答"是谁拖后腿/谁在扛"。

**输入**：该指标的公式链 + 各环节本期/上期数值。

**步骤**：
1. 画公式树（GMV = 流量 × 转化 × 客单；利润 = 各渠道利润之和）
2. 乘法链用对数/对数近似算各环节贡献率；加法链直接算贡献额
3. 贡献度降序排列
4. 对 Top1 贡献因素继续下钻一层（流量降了 → 哪个渠道降的？）

**输出**：因素 / 本期 / 上期 / 变化 / 贡献占比 五列表格 + 一句主因结论。

**坑**：乘法链各环节不独立（流量降了转化率可能被动升——来的都是精准流量）；拆解到第 2-3 层就停，再细是噪音。

---

## 2. 漏斗分析

**何时用**：转化链路有明确步骤（浏览→加购→下单→支付；注册→激活→留存）。

**输入**：各环节人数（直接给数），或含 0/1 步骤列的明细 CSV。

**步骤**：
```bash
python3 "<SKILL_ROOT>/scripts/datakit.py" funnel --counts 100000,32000,15000,9800 --labels 浏览,加购,下单,支付
# 或明细表
python3 "<SKILL_ROOT>/scripts/datakit.py" funnel 明细.csv --steps 浏览,加购,下单,支付
```
2. 看逐步转化率，定位相对流失最大环节（瓶颈）
3. 瓶颈环节继续分群：分渠道/分新老客/分端——瓶颈往往只在某一撮人身上
4. 给各环节设目标值（参照行业基准），算提升到目标值的总收益

**输出**：漏斗表 + 瓶颈定位 + 分群下钻 + "修哪步最划算"的量化测算。

**坑**：步骤口径时间窗不一致（浏览按天、支付按周 = 白算）；跨天转化被漏记；把"分步转化率"当独立事件——用户是同一批人在流动。

## 3. 留存分析 + 同期群

**何时用**：用户粘性诊断、渠道质量对比、产品改版长期效果。

**输入**：用户活跃明细（用户ID + 日期）。

**步骤**：
```bash
python3 "<SKILL_ROOT>/scripts/datakit.py" cohort 活跃明细.csv --id 用户ID --date 活跃日期
```
2. 看留存矩阵：列方向（同一群随时间衰减）+ 行方向（新群 vs 老群对比）
3. 关键对比：新同期群是否比老群留得好（产品进步证据）；不同获客渠道的群分开算
4. 拟合衰减形态：快速跌到底（产品没粘性）vs 平台期（有基本盘）

**输出**：留存矩阵 + "哪个月份的群/哪个渠道质量最好" + 衰减形态判断。

**坑**：留存定义要先定（登录算留存？还是核心行为才算？）；同期群混入大促拉新的月份要单独标注；新群时间还短，别拿 M+1 就下结论。

---

## 4. RFM 用户分层

**何时用**：用户运营资源分配、精准营销、会员体系诊断。

**输入**：订单明细（用户ID + 订单日期 + 金额）。

**步骤**：
```bash
python3 "<SKILL_ROOT>/scripts/datakit.py" rfm 订单.csv --id 用户ID --date 订单日期 --amount 金额 --out 分层明细.csv
```
2. 看八层分布：**重要价值客户**占比和收入占比（通常 20% 的人贡献 60%+ 收入）
3. 每层配策略：
   - 重要价值：专属服务、新品优先、防流失预警
   - 重要保持（最近没来但曾高频高额）：召回券、1v1 触达——**这是 ROI 最高的一层**
   - 重要挽留（很久没来、高额）：强力召回，但接受部分已流失
   - 一般发展（刚来、低频低额）：培育复购习惯，别乱发券惯坏
4. 输出分层名单（--out 的明细 CSV）给运营执行

**输出**：八层分布表 + 每层策略 + 分层名单文件。

**坑**：基准日要选分析日不是数据末日之后太久；批发/代购等 B 属性用户会污染 RFM（先剔除异常高额账号）；分层后不复用 = 白分。

## 5. ABC/帕累托分析

**何时用**：商品结构、客户结构、渠道结构——回答"集中度是否合理、长尾该不该砍"。

**输入**：维度 + 数值两列（如 商品 × 销售额）。

**步骤**：
```bash
python3 "<SKILL_ROOT>/scripts/datakit.py" abc 销售.csv --dim 商品 --value 销售额 --top 20
```
2. 看分级：A 类（累计 80%）多少个？B、C 呢？
3. 看集中度：Top1/5/10 占比——Top1 > 30% 预警单品依赖
4. C 类长尾：列"砍/留"清单（留的理由：引流款、配套款、成长期款）

**输出**：ABC 分级表 + 集中度指标 + 长尾处置建议。

**坑**：只按销售额分级会误杀高毛利款（可以再跑一遍 --value 毛利）；新品上架时间短天然在 C 类，按上架天数归一化再看。

## 6. 波动归因

**何时用**：指标突涨突跌（昨天 DAU 掉了 30%！）。

**输入**：至少 30 天的日级时间序列 + 可分维度（渠道/地区/版本）。

**步骤**：
1. 先判定"是不是真异常"：算 3σ 或同比/环比（`datakit.py profile` 看分布）；
2. 排除数据事故：采集断点、导出缺失、口径变更——**突变的头号原因永远是数据本身**
3. 维度下钻：分渠道/分端/分地区找"哪块掉得特别狠"
4. 时间对齐：异常起点附近发生了什么（发版、投放调整、大促结束、舆情）

**输出**：异常判定 + 维度定位 + 事件时间线 + 归因结论（证据强度标注）。

**坑**：周末效应/月末效应被当成异常；归因到最近一件事是人性弱点（post hoc 谬误）——要有机制性解释。

---

## 7. 假设检验（A/B 与改版评估）

**何时用**：A/B 实验结果解读、"改版后转化率涨了 0.3 个点是不是真的"。

**输入**：两组的比率+样本量，或均值+标准差+样本量。

**步骤**：
```bash
# 开实验前先算样本量！
python3 "<SKILL_ROOT>/scripts/datakit.py" sig --sample-size --baseline 0.05 --mde 0.01
# 出结果后检验
python3 "<SKILL_ROOT>/scripts/datakit.py" sig --prop-a 0.052,1200 --prop-b 0.068,1200
```
2. 样本量不够 → 直接说"继续跑"，别硬解读
3. 显著 → 再看效应量有没有业务意义（+0.01pp 显著但无用）
4. 分组复核：整体显著但新客/老客分开看（防辛普森悖论）

**输出**：p 值 + 显著性结论 + 效应量 + 业务建议。

**坑**：没到样本量就偷看结果（peeking）反复看反复停 = 假阳性制造机；多重比较（测 20 个指标总有 1 个"显著"）；样本比例失衡（SRM，50/50 实验实际 70/30 = 分流 bug）。

## 8. 趋势与预测

**何时用**：定目标、做预算、备货计划。

**输入**：时间序列（越长越好，至少覆盖 2 个完整周期）。

**步骤**：
1. 分解：趋势 + 季节（周几/月度/大促）+ 残差
2. 方法选择（由简到繁）：移动平均 → 同比外推 → 简单回归。**别上复杂模型**——数据 < 100 个点时花活儿不如常识
3. 大促月份单独处理：按去年大促系数（大促月销售额 / 前后月均）缩放
4. **必须给区间**：预测值 ± 区间，并写明假设（"假设投放预算不变、无大促政策变化"）

**输出**：趋势分解图说明 + 预测值与区间 + 关键假设清单。

**坑**：拿 3 个点画趋势线；预测不说假设；把"愿望"当预测（目标 200 万倒推出"预测 200 万"）。

## 9. 用户画像分析

**何时用**：高价值用户是谁、投放定向、产品功能优先级。

**输入**：用户属性（年龄段/城市/渠道…）+ 行为/价值字段。

**步骤**：
1. 定义目标群体（高 LTV / 高复购 / 高互动）
2. 各属性维度做交叉对比：目标组 vs 全体的占比差（TGI 思路：目标组占比 / 全体占比 × 100，>120 算显著特征）
3. 组合 2-3 个最强特征成画像（"25-35 岁 + 小红书来 + 夜间下单"）
4. 画像必须落到动作：投放定向、内容风格、选品方向

**输出**：特征对比表（含 TGI）+ 1-3 个画像卡 + 应用建议。

**坑**：画像写成星座描述（"热爱生活追求品质"）；样本小的分组 TGI 不可信；画像不变现就是壁纸。

---

## 10. 对标分析

**何时用**：找差距、定目标、回答"我们离标杆多远"。

**输入**：自家数据 + 竞品/行业公开数据。

**步骤**：
1. 选对标对象：直接竞品 + 行业标杆 + 自家历史最佳
2. 指标对齐：**先对齐口径再比较**（对方的 GMV 是什么口径？）——对不齐就只比趋势不比绝对值
3. 差距拆解：总量差距 → 结构差距（渠道结构、客单结构）
4. 输出可追赶项：差距中哪些是可学的（打法），哪些是资源禀赋（学不会）

**输出**：对标表 + 差距拆解 + "可学/不可学"清单。

**坑**：公开数据多为口径美化过的（战报 GMV）；拿对方高光时刻比自己日常；比完只有焦虑没有动作。
