# 六大行业指标字典与健康基准线

按行业查指标口径和"多少算健康"。基准线是国内市场经验值，用于快速判断量级——**不同商业模式差异很大，基准只是锚，不是标准答案**。

## 1. 电商（平台店铺 / 抖店 / 天猫）

| 指标 | 口径 | 健康参考 |
|---|---|---|
| GMV | 注意拍下/支付/净成交三口径 | — |
| 转化率 | 支付买家数 / 访客数 | 货架电商 2-5%；直播电商 5-15% |
| 客单价 | GMV / 支付买家数 | 看类目，服饰 100-300，家电 1000+ |
| UV 价值 | GMV / 访客数 | 货架 3-8 元 |
| 复购率 | 90 天内购买 ≥2 次用户占比 | 快消 25%+，耐用品天然低 |
| 退货率 | 退款金额 / GMV | 服饰直播 40-60% 常见，标品 <10% |
| 动销率 | 有销量 SKU / 总 SKU | >70% |
| 千次曝光成交 GPM | GMV / 曝光 × 1000 | 抖音核心效率指标，看类目大盘 |

**抖音电商特供**：GPM、直播间观看-成交转化率、千川 ROI（保本 ROI = 1/毛利率）。

## 2. 零售门店

| 指标 | 口径 | 健康参考 |
|---|---|---|
| 坪效 | 月销售额 / 面积(㎡) | 便利店 1500-3000 元/㎡/月 |
| 连带率 | 销售件数 / 交易笔数 | 服饰 1.6+，低于 1.3 要练搭配销售 |
| 进店转化率 | 成交人数 / 进店人数 | 20-40% |
| 会员销售占比 | 会员消费 / 总销售 | >50% 说明老客经营扎实 |
| 库存周转天数 | 平均库存 / 日均销货成本 | 服装 60-90 天，超市 30-45 天 |
| 同店增长 | 开业满一年门店的同比 | 正增长是扩张的前提 |

## 3. 餐饮

| 指标 | 口径 | 健康参考 |
|---|---|---|
| 翻台率 | 日接待桌数 / 总桌数 | 快餐 4-8，正餐 1.5-3 |
| 桌均消费 | 营业额 / 接待桌数 | — |
| 人效 | 营业额 / 员工数 | — |
| 食材成本率 | 食材成本 / 营业额 | 28-35%，超过 40% 亮红灯 |
| 房租占比 | 房租 / 营业额 | <15%，超过 25% 很难赚钱 |
| 会员复购 | 30 天回头客占比 | 快餐 30%+ |

## 4. SaaS / 订阅制

| 指标 | 口径 | 健康参考 |
|---|---|---|
| MRR / ARR | 月/年经常性收入 | — |
| NDR 净收入留存 | 老客户今年收入/去年同期（含增购减流失） | >100% 是优秀线，>120% 顶级 |
| 月流失率 | 当月流失客户 / 期初客户 | 小客户型 <3%/月，大客户型 <1%/月 |
| LTV/CAC | 客户终身价值 / 获客成本 | >3 |
| CAC 回收期 | CAC / (月均客单 × 毛利率) | <12 个月 |
| 免费转付费率 | 试用转付费占比 | 2-5%（freemium），15-25%（试用制） |

## 5. 内容平台 / 自媒体（公众号/抖音/小红书）

| 指标 | 口径 | 健康参考 |
|---|---|---|
| 打开率 | 公众号：阅读/送达 | 2-5%（订阅号整体下滑中） |
| 完播率 | 看完视频占比 | 抖音 >15% 算不错，>30% 爆款相 |
| 互动率 | (赞+评+转+藏)/曝光 | 小红书 >5% 优质 |
| 涨粉效率 | 单篇涨粉 / 阅读 | 看内容类型 |
| 5 秒完播率 | 前 5 秒留存 | 抖音 <50% 说明开头垮 |
| 转粉率 | 新增关注 / 主页访问 | — |

## 6. App / 互联网产品

| 指标 | 口径 | 健康参考 |
|---|---|---|
| DAU/MAU 粘性比 | 日活/月活 | >20% 及格，社交 >50% |
| 次日留存 | 新增次日回访占比 | 工具 25%+，内容 35%+，社交 45%+ |
| 7 日 / 30 日留存 | 同上 | 7 留 >15%，30 留 >8% 起步 |
| 获客成本 CAC | 投放费用 / 新增 | 对比 LTV 判断 |
| 崩溃率 | 崩溃次数 / 启动次数 | <0.1% |

## 使用纪律

1. **基准线先问口径**：别人报的"留存"是次日还是次周、是账号还是设备，对不上就是耍流氓
2. **看趋势重于看绝对值**：自家指标的环比/同比趋势，比对标基准线更可靠
3. **分渠道看**：大盘平均掩盖结构差异，抖音来的客和搜索来的客不是一个物种
