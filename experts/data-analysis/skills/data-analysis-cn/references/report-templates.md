# 报告模板（三级交付物）

按受众选模板：老板看一页纸，团队看完整报告，行家查附录。

---

## 模板 A：一页纸摘要（给老板/决策者）

> 全部内容必须在一页内，结论先行，最多三个关键数字。

```markdown
# 【数据分析】<一句话结论>

**结论**：<核心发现一句话，例：6 月销售下滑主因是抖音投放缩减，不是产品问题>

**三个关键数字**：
1. <指标>：<数值>（<环比/同比>）
2. <指标>：<数值>（<对比基准>）
3. <指标>：<数值>（<含义>）

**建议动作**（按优先级）：
1. 【高】<动作> —— 预期影响：<…>，负责人：<…>，验证方式：<…>
2. 【中】<动作> —— …

**需要决策**：<需要老板拍板什么？批预算？定方向？>

证据强度：✅/🟡/⚪    分析窗口：<日期范围>    数据质量：A/B/C/D
```

**写作纪律**：
- 第一句话就是结论，别铺垫
- 数字给环比/同比基准，孤立的数字没有意义
- 每条建议必须写"预期影响"和"怎么验证"
- 不写过程、不写方法——都在完整报告里

## 模板 B：完整分析报告（给团队/存档）

```markdown
# <主题>分析报告
日期 / 分析人 / 数据窗口

## 1. 一页摘要
（模板 A 的内容复制到这里）

## 2. 背景与目标
- 业务问题：<原始诉求>
- 分析命题：<翻译后的可分析命题>
- 成功标准：<这份分析要能支持什么决策>
- 边界：<明确不分析什么>

## 3. 数据与方法
- 数据来源与可信度分级
- 口径说明：<关键指标定义>
- 数据质量：评分 + 清洗决策摘要 + 风险声明
- 分析方法：<用了哪些打法>

## 4. 核心发现
### 发现 1：<标题>
- 数据：<表格/图表说明>
- 解读：<这意味着什么>
- 证据强度：✅/🟡/⚪
### 发现 2：…

## 5. 结论与行动建议
| 优先级 | 建议 | 依据 | 预期影响 | 验证方式 | 负责人 |
|---|---|---|---|---|---|

## 6. 附录
- 口径定义详表
- 清洗决策留痕（datakit clean 的日志）
- 显著性检验过程
- 复核官挑战记录
```

**结构纪律（金字塔原理）**：结论 → 分组论点 → 数据支撑。读者随时可以停在某一层的深度。

## 图表选型速查

| 目的 | 图表 | 备注 |
|---|---|---|
| 趋势 | 折线 | 时间序列默认 |
| 对比 | 柱状/条形 | 类别 ≤7 用柱，>7 用横条 |
| 占比 | 环形 | ≤6 个扇区，多了就"其他"合并 |
| 转化 | 漏斗 | datakit funnel 直出 |
| 分布 | 直方/箱线 | 别只看均值 |
| 关系 | 散点 | 相关性的正确打开方式 |
| KPI | 大数字卡 | 配趋势箭头和环比 |

出图联动：使用宿主实际可用的图表或演示文稿工具；工具不可用时交付图表建议和逐页提纲。
