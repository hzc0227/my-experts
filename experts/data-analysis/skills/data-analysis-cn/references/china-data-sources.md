# 国内数据源与口径手册

用外部数据前必读——国内主流数据源各自口径不同，混用必翻车。

## 1. 官方统计

| 来源 | 内容 | 口径要点 |
|---|---|---|
| 国家统计局 | 宏观、行业、消费（社会消费品零售总额） | "社零"不含餐饮以外服务消费；月度发布有季调/未季调两版 |
| 央行/金融监管 | 金融、支付数据 | — |
| 行业白皮书 | 中国互联网络信息中心 CNNIC（网民规模）、信通院 | 年度/半年度，发布滞后 1-2 个月 |

## 2. 上市公司数据

- **财报**：A 股（巨潮资讯）、港股、美股——营收口径见会计附注；"GMV" 阿里/京东/拼多多各自定义不同且陆续停止披露，跨平台比较 GMV 基本不可比
- **业绩会/电话会纪要**：管理层口径往往比财报细（如分业务线增速），但带管理层美化倾向

## 3. 第三方监测

| 平台 | 擅长 | 口径坑 |
|---|---|---|
| QuestMobile | App 月活/时长 | 是抽样估算不是全量；和自家埋点差 10-30% 都正常，看趋势别看绝对值 |
| 蝉妈妈/蝉小红/飞瓜 | 抖音/小红书 直播带货、达人数据 | 带货 GMV 是"按销量×标价"的估算，不含退货，和商家后台差距大 |
| 生意参谋（淘系）/ 抖店罗盘 | 自家店铺经营数据 | 自己店铺的数据最准；行业大盘是平台脱敏后的指数化处理 |
| 艾瑞/易观 | 行业报告 | 部分报告为定制付费内容，注意屁股位置 |
| 久谦/窄门餐眼 | 餐饮门店数据 | 爬取数据有滞后和遗漏 |

## 4. 平台后台（一手数据，可信度最高）

- 抖店罗盘、千川后台、生意参谋、微信广告主后台、小程序数据助手
- **优先级铁律**：自家业务系统 > 平台后台 > 第三方估算 > 媒体报道 > 网传截图
- 平台后台和媒体数据对不上时，**以自家后台为准**，第三方只看趋势方向

## 5. 口径对不上时的处理流程

1. 先查定义：分母是什么？时间窗？去重逻辑（设备/账号/手机号）？
2. 能校准的校准：同一指标两个来源，算长期稳定的换算系数（如 QM ≈ 自家埋点 × 1.2）
3. 不能校准就放弃绝对值对比，只比趋势方向和相对排名
4. 报告里必须注明来源和口径——"数据来源：蝉妈妈估算（未含退货）"

## 6. 合规红线（PIPL 个人信息保护法）

- 用户明细数据进入分析前**必须脱敏**：手机号/身份证/姓名不出现在分析文件里，用 ID 哈希替代
- 分析报告只输出聚合结果，不输出可定位到个人的明细（RFM 分层名单给运营是业务用途，报告里不出现）
- 竞品/用户数据只用公开来源和授权渠道，不爬取、不买来路不明的"数据包"
- 涉及用户画像的输出，标注"统计数据，不构成对个体的判断"
