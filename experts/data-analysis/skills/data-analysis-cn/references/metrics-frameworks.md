# 指标框架手册

北极星 / AARRR / 人货场 / 杜邦拆解 / GMV 公式族——做指标拆解前先在这里选对框架。

## 1. 北极星指标（North Star Metric）

**定义**：唯一最能代表产品长期价值的核心指标，全公司对齐它。

**选法三问**：
1. 它是否反映用户获得的核心价值？（不是"公司赚了多少钱"）
2. 它是否可以被团队行动影响？
3. 它是否是滞后结果而非虚荣指标？

**常见锚点**：
- 电商：月度复购用户数（不是 GMV——GMV 可以被补贴硬拉）
- 内容平台：周消费时长 / 周活跃创作者数
- SaaS：周活跃企业数 / 核心功能周使用次数
- 私域：月互动用户数（不是好友总数——僵尸粉是虚荣指标）

**配套护栏指标**：北极星涨的同时，护栏不能崩。例：追 GMV 时护栏是退货率和毛利率；追时长时护栏是用户留存（防止用低俗内容拉时长）。

## 2. AARRR 海盗模型（获客漏斗）

**获取（Acquisition）→ 激活（Activation）→ 留存（Retention）→ 推荐（Referral）→ 收入（Revenue）**

| 环节 | 核心问题 | 常用指标 | 国内典型渠道 |
|---|---|---|---|
| 获取 | 用户从哪来？ | 新增用户、获客成本 CAC、渠道占比 | 抖音/小红书/视频号/朋友圈广告/地推 |
| 激活 | 第一次"啊哈时刻"到了吗？ | 注册完成率、首单转化、新手任务完成率 | 首单礼金、新客专享 |
| 留存 | 还会回来吗？ | 次日/7日/30日留存、同期群曲线 | 签到、会员日、召回短信 |
| 推荐 | 愿意拉人吗？ | NPS、分享率、裂变系数 K | 拼团、老带新奖励 |
| 收入 | 掏钱了吗？ | 付费率、ARPU、LTV | 会员、复购、增购 |

**用法**：先定位漏斗里哪一环最弱（用 `datakit.py funnel`），再决定打哪。不要五线作战。

**健康直觉**：K > 1 才是自增长；LTV/CAC > 3 才算健康生意；次留 < 20% 的 App 拉新是在漏水桶里加水。

## 3. 人货场（零售/电商拆解框架）

- **人**：用户结构（新客/老客、RFM 分层、会员等级）、获客成本、转化率、复购率
- **货**：商品结构（ABC 分级、动销率、毛利率、库存周转）、爆品依赖度（Top1 SKU 占比 > 30% 是高风险）
- **场**：渠道结构（抖音/天猫/私域/门店各自占比与效率）、坪效、场景转化

**用法**：经营下滑先按人货场三分法定性——是没人来（人）、货不对（货）、还是场子选错（场）？再用数据往深钻。

## 4. 杜邦拆解（利润/ROI 归因）

净资产收益率 ROE = 净利率 × 资产周转率 × 权益乘数。

生意版拆解（电商/零售通用）：

```
利润 = GMV × 毛利率 − 费用
GMV = 流量 × 转化率 × 客单价
流量 = 曝光 × 点击率
转化率 = 下单人数 / 访客数
客单价 = 件单价 × 连带率（件数/单）
```

**拆解规则**：
- **乘法链**：各环节的变化率近似相加（对数意义下）。GMV -12% = 流量 -20% + 转化 +9% + 客单 -1%，主因一眼看出
- **加法链**：利润 = A 渠道利润 + B 渠道利润，算各渠道利润变化的贡献额
- 贡献度排序表是标配输出：因素 / 变化 / 对总变化的贡献 / 贡献占比

## 5. GMV 公式族（电商必备）

```
GMV = 访客数 × 转化率 × 客单价
    = (老访客 + 新访客) × 转化率 × 客单价
    = Σ(各渠道 GMV)
    = 支付金额 + 退款金额（注意口径！）
```

**口径三坑**（国内平台常见）：
1. **拍下口径 vs 支付口径**：平台战报多用拍下 GMV（含未付款），自己生意参谋看支付口径，两者能差 20%+
2. **含退款 vs 净成交**：大促后退货率飙升（服饰类目退货率 40%+ 不罕见），复盘用净成交
3. **预售算不算**：双11 预售期成交额计在哪天，各平台口径不同

## 6. 指标体系搭建步骤

1. 定北极星（一个）
2. 拆驱动公式（乘法链优先）
3. 每个环节配 1-2 个过程指标
4. 配 2-3 个护栏指标
5. 定义每个指标的**口径文档**（谁定义、怎么算、从哪取数、多久更新）——口径文档缺失是国内团队数据分析翻车的头号原因
