# 统计红线手册

统计学家的底线工具箱：每条红线配"怎么判断 + 怎么办"。深度分析阶段每走一步都要过一遍。

## 一、显著性与样本量

**核心问题**：观察到的差异是真实差异，还是随机波动？

**快速判断**：
- 两比率比较：`datakit.py sig --prop-a 率,量 --prop-b 率,量` → p < 0.05 才算"显著"
- 两均值比较：`datakit.py sig --mean-a 均值,标准差,量 --mean-b ...`
- 开实验前：**先算样本量** `datakit.py sig --sample-size --baseline 0.05 --mde 0.01`——转化率 5% 想测出 ±1pp 差异，每组要 8000+ 样本。样本不够的差异都是噪音

**直觉校准**：
| 样本量 | 能可靠检测的差异（基线 5% 转化） |
|---|---|
| 每组 100 | ±4.4pp（几乎翻倍才能看出来）|
| 每组 1,000 | ±1.4pp |
| 每组 10,000 | ±0.44pp |
| 每组 100,000 | ±0.14pp |

**红线**：p < 0.05 只说明"不像随机"，不说明"重要"。**显著 ≠ 重要**——1 亿样本下 0.001pp 的差异也显著，但没有业务价值。永远同时报告效应量。

## 二、十大偏差与红线详解

### 1. 相关 ≠ 因果
冰淇淋销量和溺水人数同涨——都是夏天。数据分析给的永远是相关；要谈因果，需要实验（A/B）、自然实验或至少控制混杂后的准因果推断。**表述纪律**：没做实验就写"X 与 Y 相关/同步变化"，不写"X 导致 Y"。

### 2. 辛普森悖论
分组里都涨，总体却跌（或反过来）——因为组间结构变了。例：新老客转化率都涨，但总转化率跌了，因为低转化的新客占比变高。**防御**：任何总体结论必须分组复核（新老客/渠道/端）。

### 3. 幸存者偏差
分析"留存用户的特征"总结成功经验——走了的人你没看到。例：分析续费客户共同点 ≠ 找到续费驱动，可能流失客户也有这些点。**防御**：结论需要对照组（流失组什么样？）。

### 4. 确认偏误
先有结论"投放没用"，再挑数据证明它。**防御**：复核官强制问"什么证据能推翻这个结论"，并主动去找。

### 5. 口径漂移
上月的"活跃用户"和这月的定义不同、去年 GMV 是拍下口径今年是支付口径。**防御**：对比前先核口径文档；口径变更点在时间序列上打标记。

### 6. 样本量不足
12 个样本里 8 个好评 = "好评率 67%"？置信区间 ±27pp，等于什么都不知道。**防御**：小样本只给方向性观察，标注 ⚪ 待验证。

### 7. P 值迷信
追求 p<0.05 而忽略效应量与成本；或者反复实验直到某次显著（p-hacking）。**防御**：实验前定好"显著且有业务意义"的双重标准。

### 8. 大促/季节脉冲当趋势
双11 后两周必跌（透支消费），618 前一周必憋单。**防御**：大促窗口（618 前 3 天~后 7 天、双11 前 7 天~后 10 天）单独剔除或用同比；分析月报时标注大促影响。

### 9. 均值掩盖分布
客单价均值 300，实际是中位 80 + 一批批发大单拉的。**防御**：均值永远配中位数/分位数看（`datakit.py profile` 同时给出）；警惕头部 1% 用户/商品的绑架效应。

### 10. 数据完美得可疑（造假信号）
- 零退货率、零差评
- 流量整点/半点脉冲式爆发（机器刷量特征）
- 转化率小数点后整齐重复（2.50%、3.00%…）
- 新客占比异常高但留存一致得好
- 环比稳定增长得过于平滑（真实生意有噪音）

**防御**：看到"完美数据"先怀疑，要求看原始明细而非汇总表；交叉验证（流量涨了，服务器日志/客服咨询量同步吗？）。

## 三、判断流程（每步自问）

```
观察到差异/趋势
   ├─ 数据本身有问题吗？（采集断点/口径变更/导出事故）→ 先修数据
   ├─ 样本量够吗？ → 不够：标 ⚪ 待验证，不收结论
   ├─ 是季节/大促/周末效应吗？ → 剔除或用同比
   ├─ 分组后还成立吗？（辛普森防线）→ 不成立：按分组重新叙述
   ├─ 统计显著吗？ → 不显著：写"未观察到可靠差异"
   ├─ 显著了，效应量有业务意义吗？ → 没有：不值得行动
   └─ 有其他解释吗？（复核官环节）→ 有：降级证据强度
```
