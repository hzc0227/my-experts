# 复核官红队挑战清单

任何结论交付用户之前，复核官必须逐项过这份清单。**每条结论都要能经受住这三类挑战，否则降级或打回。**

## 挑战一：替代解释（这个问题还能怎么解释？）

- [ ] 这个趋势/差异，除了我们的解释，还有哪些可能？（至少再想 2 个）
- [ ] 是需求变了，还是供给/价格/渠道变了？
- [ ] 是我们做的好，还是大盘都在涨？（行业背景查了吗）
- [ ] 是不是季节/周末/大促/天气/发薪日的常规波动？
- [ ] 分渠道、分新老客、分端看，结论还成立吗？

## 挑战二：口径与数据质量（数字本身可信吗？）

- [ ] 对比的两期数据口径完全一致吗？（指标定义、统计窗口、取数系统）
- [ ] 数据质量报告里的风险声明，会影响这个结论吗？
- [ ] 样本量够吗？置信区间多宽？
- [ ] 有没有缺失/重复/异常值正好集中在关键时间段或关键分组？
- [ ] 汇总数据和明细能对上吗？（抽查过原始行吗）
- [ ] 数据来源是几级可信度？（口头估算来的数字不能进核心结论）

## 挑战三：因果链（从"看到"到"因为"跨了几步？）

- [ ] 结论是相关还是因果？表述里有没有偷换？（"X 导致 Y" 还是 "X 与 Y 同步"）
- [ ] 时间先后对吗？（先涨价后跌量，还是跌量后才涨价）
- [ ] 有没有反向因果的可能？（不是会员更爱买，是爱买的成了会员）
- [ ] 有没有第三变量同时驱动两者？（活动同时带来了流量和转化）
- [ ] 如果要确认因果，需要补什么证据？（实验/断点/自然实验）

## 挑战四：行动有效性（建议站得住吗？）

- [ ] 建议的动作和发现之间有逻辑闭环吗？
- [ ] 预期影响的测算是基于什么假设？（假设写在纸面上了吗）
- [ ] 执行成本算过吗？ROI 为正吗？
- [ ] 有没有更便宜的方式先验证？（小流量实验 > 全量铺开）
- [ ] 建议失败了怎么知道？监控指标和止损线定了吗？

## 裁决规则

| 挑战结果 | 处置 |
|---|---|
| 四类全过 | ✅ 强证据，正常交付 |
| 有替代解释无法排除 | 🟡 降级为间接证据，结论里写明"另一种可能是…" |
| 口径/样本硬伤 | ⚪ 标"待验证"，明确写出补什么数据/做什么实验 |
| 因果链断裂且无法补救 | ❌ 打回，该结论不得出现在交付物里 |

## 复核记录格式（附在报告附录）

```
结论：6 月 GMV 下滑主因是抖音投放缩减
替代解释排查：①行业大盘（6 月类目大盘 -3%，我们 -12%，解释部分但非全部）
             ②价格因素（未调价）③竞品动作（无大动作）
口径核对：两期均为支付口径 ✅
因果链：投放缩减(5/28) → 流量下滑(6/1 起) → GMV 下滑，时间序成立
裁决：🟡 间接证据 —— 建议恢复投放做两周小步验证
```
