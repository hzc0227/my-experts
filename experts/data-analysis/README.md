# 数据分析专家团（DSH 适配版）

按需求澄清、数据理解、清洗、探索、深度分析、洞察、复核、报告和复盘组织数据分析，保留六种职责、七个 CSV 分析子命令和八篇参考文档。

## 安装与使用

将专家管理插件的内置仓库配置为 `https://github.com/hzc0227/my-experts.git`，分支 `main`，同步后在「专家团」列表安装本专家。在输入框选择本专家或输入 `/expert-data-analysis`，附上业务问题和数据文件。

默认由当前会话按角色文件分阶段执行。插件注入团长正文与关联技能链接，不自动创建六个代理；团长按需读取其余成员文件。有实际子代理能力和委派授权时可拆分任务，自查与独立复核分别标注。

## 文件与环境

- `.codebuddy-plugin/plugin.json`：专家管理插件要求的入口文件，包含团队、角色及技能声明。
- `agents/`：团长与五种协作职责。
- `skills/data-analysis-cn/`：分析流程、参考文档和标准库 Python 工具。
- `avatars/`：团队与成员头像。

工具支持 CSV；Excel 需要可用的表格转换能力。图表与演示文稿按宿主实际能力交付，缺少工具时提供表格或提纲。工具路径从实际安装目录解析，不依赖本机固定路径。
