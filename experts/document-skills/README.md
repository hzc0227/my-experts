# 文档处理助手

面向 DSH 的单人专家，提供 Word、Excel、PowerPoint 和 PDF 的任务路由与文件处理规范。作者与维护者：hanzhichao7。

## 使用

专家管理插件内置源配置为 `https://github.com/hzc0227/my-experts.git`、分支 `main`。保存并同步，在「内置」安装文档处理助手，再输入 `/expert-document-skills` 或从专家菜单选择。

输入待处理文件、目标格式和需要保留的内容。专家按文件类型读取随包的四份技能说明，再使用宿主实际提供的工具或本机已安装的库执行任务。

## 默认行为

- 输出新文件，保留原始输入；目标重名时选择新名称。
- 新建批注与修订的作者默认 `JdiWorker`，用户明确指定时按用户要求；保留已有历史署名。
- 处理后回读，区分内容检查、公式重算和视觉检查的实际完成情况。
- 批量任务先验证一个样例，再记录每个文件的成功与失败。

## 环境要求

本包仅包含角色与技能说明，不捆绑执行工具，不自动安装依赖。优先使用宿主可用的文档工具；脚本处理时按任务选择已安装的 Python/Node 库。LibreOffice、Pandoc、Poppler 和 Tesseract 等程序按转换、渲染或 OCR 需求检查；缺失时说明限制或提供替代交付。

随包技能未注册为四个全局技能；专家提示词提供文件链接并引导按需读取。无需依赖其他同名技能，宿主另有相关技能时读取其用法再复用。

## 内容与验证范围

此版本新写了角色与四份技能说明，未复制本机第三方专有技能的正文、脚本、图像或许可证。文件创建、转换和版式效果取决于宿主工具与运行环境；静态格式检查不代表端到端处理能力已经验证。
