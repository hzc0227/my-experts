# 演示文稿处理

本技能由文档处理助手按任务读取。文件保护、批注修订作者和交付说明遵循专家角色定义；工具调用以当前宿主实际能力为准。

## 操作步骤

1. 确认受众、汇报目标、时长、页数和模板要求。已有模板先检查页面尺寸、母版、字体、占位符、图表和备注。
2. 优先使用宿主已有的演示工具。脚本可按实际安装情况使用 `python-pptx` 或 PptxGenJS；使用前确认库可用。复制模板时在副本上编辑，保留原模板。
3. 新建演示先确定逐页结论和支撑数据，再排版。模板替换定位具体占位符、段落或表格，核对出现次数，避免整页文本覆盖破坏格式。图表数据和文字说明使用同一份已核对的数据。
4. 字体、图片和图表资源使用可访问且允许使用的文件。图片保持比例，图表注明单位和时间范围；不在没有数据时填造数值。
5. 回读生成文件，核对页数、页面尺寸、标题、关键数字及图片引用。若可用，使用 LibreOffice 等渲染程序在副本上导出 PDF 或页面图，检查文字溢出、遮挡、截断、字体替换和图表可读性。
6. 没有渲染程序时明确仅验证结构与文本；没有 PPTX 生成能力时交付逐页提纲，并说明没有生成演示文件。

## 格式限制

PPTX 与旧版 PPT 不能靠改扩展名互换。动画、复杂母版、嵌入媒体和图表在第三方库或 PDF 导出中可能不被保留；任务要求这些内容时先确认工具支持，再执行转换。已知损失需要用户同意后再按降级方案交付。
