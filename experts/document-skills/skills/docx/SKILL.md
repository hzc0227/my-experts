# Word 文档处理

本技能由文档处理助手按任务读取。文件保护、批注修订作者和交付说明遵循专家角色定义；工具调用以当前宿主实际能力为准。

## 操作步骤

1. 明确是新建、模板填充、提取还是带修订的编辑。读取输入文档的段落、表格、页眉页脚与样式；涉及文本框、脚注和批注时单独检查对应结构。
2. 优先使用宿主已有的 Word 编辑工具。脚本处理普通 DOCX 时可使用已安装的 `python-docx` 或 `docx`；提取或转换可使用实际可用的 Pandoc、LibreOffice。先检查版本或库是否可导入。
3. 模板替换按业务字段定位，核对匹配次数。文本可能分布在多个 run 中；避免用整段纯文本赋值破坏局部格式。只修改用户指定的内容，保留其他结构。
4. 批注和修订沿用专家角色中的作者规则。工具不能保留或创建目标结构时，先说明限制；需要修改 OOXML 时保留命名空间、关系和内容类型，并检查修改后的引用，不用纯文本替换冒充修订记录。
5. 保存到新 DOCX 后重新打开，核对替换次数、目标文本、表格与样式。使用 `zipfile.ZipFile.testzip()` 可辅助检查 ZIP 完整性，但不能替代文档结构和排版验证。
6. 需要 PDF 或页面版式时，在转换程序可用的情况下导出并渲染，检查换页、表格、页眉页脚和字体。没有渲染条件时明确仅完成结构与内容检查。

## 输出约束

DOCX、旧版二进制 DOC 和 PDF 是不同格式，不能通过改扩展名转换。工具不支持保留修订、宏或嵌入对象时，不静默丢弃；先说明可完成的范围。输出处理后的文档和需要用户复核的项目。
