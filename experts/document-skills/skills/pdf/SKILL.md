# PDF 文档处理

本技能由文档处理助手按任务读取。文件保护、批注修订作者和交付说明遵循专家角色定义；工具调用以当前宿主实际能力为准。

## 操作步骤

1. 检查页数、页面尺寸、旋转方向、文本层、表单字段及是否存在加密限制。先抽查内容，区分文字型、扫描型和混合型文档。
2. 优先使用宿主已有的 PDF 工具。脚本可按实际安装情况用 `pypdf` 做页级操作和表单处理、`pdfplumber` 提取文本表格、ReportLab 创建 PDF。渲染与 OCR 分别检查可用的 Poppler、Tesseract 或其他工具，不假设中文识别模型存在。
3. 提取结果标明原始页码。表格核对表头、跨页延续、合并单元格和金额总计；无法可靠恢复的单元格保留不确定标记，不编造缺失值。
4. 扫描页先渲染，再用具有对应语言模型的 OCR 工具识别。文字页优先保留原文本层；混合页避免重复提取。抽查金额、日期和编号，报告实际发现的识别错误，不宣称固定准确率。
5. 合并、拆分或旋转按用户给定的页序执行。用户页码以 1 为起点，调用从 0 开始的 API 时显式换算并校验范围。表单填写后回读字段值；数字签名和原始签署文件予以保留，输出修改副本并说明签名有效性需另行核验。
6. 回读输出 PDF，检查页数、页序、字段值和关键文本。涉及页面呈现时，工具可用则渲染抽查或逐页检查；缺少条件时说明未验证视觉效果。

## 转换与交付

PDF 转可编辑 Word 是内容与布局重建，不能保证与原稿完全相同。优先输出带页码的提取内容，再按用户目标生成文档；格式精度不足时保留原页图供核对。加密文件需要用户提供合法访问凭据，不把读取失败报告为空文档。新建中文 PDF 时使用可用且允许嵌入的中文字体，并验证显示效果。
