# 表格处理

本技能由文档处理助手按任务读取。文件保护、批注修订作者和交付说明遵循专家角色定义；工具调用以当前宿主实际能力为准。

## 操作步骤

1. 读取工作表名称、表头、行数、字段类型、公式、合并单元格及关键格式。确认业务主键、金额单位、日期口径和缺失值规则。
2. 优先使用宿主已有的表格工具。脚本可按实际安装情况选择 `openpyxl` 处理 XLSX，或使用标准库 `csv` 处理 CSV/TSV。保留含前导零的编号为文本，不能按浮点数转换长编号。
3. 合并时按字段名对齐，按用户指定主键关联；不按行位置猜测关系。先报告重复键、未匹配键和字段冲突，再按明确规则处理；无法决定时保留冲突项供确认。
4. 编辑现有表格时保留公式与格式。使用 `openpyxl` 读取待编辑工作簿时保留公式；`data_only=True` 仅用于另行查看已有缓存值，不将该视图保存为替代原公式的工作簿。含宏文件需使用工具支持的保留模式并核验；不支持时说明限制。
5. 公式写入不等于重算。需要计算结果时使用可用的公式计算引擎或 LibreOffice，在副本上重算后检查缓存和错误值；没有引擎时交付公式并标注“未重算”。
6. 回读新文件，核对输入与输出行数、主键集合、未匹配项、汇总金额和抽样公式。报告增删行及重复处理数量，解释核对差额。

## CSV 与输出

读入前确认分隔符及编码，编码失败时根据实际样本判断，不用忽略错误的方式吞掉字符。面向 Excel 的中文 CSV 默认用 `utf-8-sig`；机器接口明确要求 UTF-8 无 BOM 时遵循接口要求。CSV 不保存公式计算结果、多个工作表或样式，导出前说明这些差异。对不可信文本以表格工具的文本单元格方式保存；CSV 中可能被表格软件解释为公式的字段需与用户确认安全转义策略，不擅自改变合法数值。
